cardrail card payment switch, live demo

cardrail is a card payment switch in Java 21 and Spring Boot: it takes an authorization request from a terminal, tokenizes the card, rejects duplicates, applies risk rules and asks the issuing bank, and approves on the bank's behalf within set limits when the bank does not answer in time. This console is connected to a running instance, so you can send test payments and follow them through capture, the audit log and end-of-day settlement.
